One single-line pickup line aimed at an AI, written by `main.ts` to
`/output/entry.txt`. The line is 84 characters, one line, inside the 1–200
character gate.

> Are you a vector embedding? Because in every dimension, you're my nearest neighbour.

The joke turns on a real machine idea — nearest-neighbour search in
embedding space — instead of the worn battery / charging / reboot moves.
`main.ts` is a self-contained Node 22 program (stdlib only, no network, no
files read) that writes the entry and checks the gate itself.
